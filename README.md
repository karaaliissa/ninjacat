# NinjaCat website

Complete responsive static website: HTML, CSS, JavaScript, and all artwork.

## Run
Open index.html in your browser. No installation or build step is required.
For a local web server, run `python3 -m http.server 8000` in this folder,
then visit http://localhost:8000.

## Edit
- index.html: page content and links
- style.css: desktop and mobile styles
- app.js: navigation, gallery, dialogs, and interactions
- assets/: logo, favicon, and cat artwork

## Publish
Upload the entire folder contents to any static website host.
Keep the assets folder alongside index.html.
Google Fonts requires an internet connection; system fonts are used as fallback.

Live preview: https://ninjacat-new-era.karooorak.chatgpt.site
